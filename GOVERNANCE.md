# Governance

Finally Server is maintained by [@kaungzinye](https://github.com/kaungzinye). Vikunja remains an independent upstream project with its own maintainers and governance.

## Decisions

Issues and pull requests are the public record for fork-specific product and technical decisions. The maintainer weighs client compatibility, security, privacy, operational cost, upstream drift, and maintainability. The maintainer has final responsibility for merges, releases, security advisories, and repository settings.

General-purpose fixes should move upstream when practical. Finally-specific changes stay narrow and avoid altering inherited behavior outside their documented scope.

## Contributors

Anyone may report bugs, propose changes, improve documentation, review code, or submit pull requests. Sustained, useful participation may lead to repository access. The maintainer grants and removes access based on project needs and security risk.

## Changes to governance

Governance changes use a pull request that explains their effect on this fork, its contributors, and its upstream relationship.
