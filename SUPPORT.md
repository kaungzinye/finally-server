# Support

Finally Server is maintained as an open-source fork. Support is provided on a best-effort basis.

## Finally-specific help

Search the [issue tracker](https://github.com/kaungzinye/finally-server/issues), then open a bug report for problems involving:

- `/api/v2/finally` client routes;
- Finally client compatibility;
- private calendar context;
- fork-specific configuration or deployment behavior.

Include the commit or release, database type, deployment method, expected result, actual result, and minimal reproduction steps. Remove tokens, credentials, task content, event content, email addresses, and private hostnames.

## Upstream help

Use [Vikunja's documentation](https://vikunja.io/docs/) and [community](https://community.vikunja.io/) for general Vikunja installation, frontend, migration, and administration questions. Report a general Vikunja defect upstream when it reproduces without Finally Server changes.

Security reports belong in the private channel described in [SECURITY.md](SECURITY.md). The public issue tracker does not provide emergency response or managed-hosting support.
